# 로봇 팔 동역학: 중력·코리올리·원심력 토크

---

## 1. 로봇 팔 운동 방정식 (전체 그림)

```
관절 토크 입력
     τ
     │
     ▼
┌─────────────────────────────────────────┐
│  M(q)·q̈  +  C(q,q̇)·q̇  +  g(q)  =  τ  │
└─────────────────────────────────────────┘
     │              │            │
     ▼              ▼            ▼
  관성 항       코리올리+      중력 항
 (가속 저항)    원심력 항
```

τ를 직접 제어 입력으로 쓰는 **토크 제어 로봇**에서 이 식이 성립해.

## 2. 중력 토크 g(q)

### 개념

```
         ●  end-effector
        /
       / L₂         중력 g ↓
      /
     ●  joint 2
    /
   / L₁
  /
 ●  joint 1 (base)
```

각 링크의 무게중심에 작용하는 중력이 관절에 토크를 만들어.

### 계산식

링크 i의 무게중심 위치를 `pᵢ(q)` 라 하면:

```
         n
g(q) = - Σ  mᵢ · Jvᵢ(q)ᵀ · gvec
        i=1

gvec = [0, 0, -9.81]ᵀ  (중력 벡터)
Jvᵢ  = 링크 i 무게중심의 선속도 자코비안
mᵢ   = 링크 i 질량
```

### 직관적 이해

```
joint 1만 있는 경우:

  q=0°        q=90°
   ●─────    ●
   │              │
   ▼ mg           ▼ mg

  토크=0     토크=mg·L  (최대)
```

팔이 수평일수록 중력 토크가 커짐. `g(q)`는 자세에 따라 변하기 때문에 **q의 함수**야.

## 3. 코리올리 토크

### 개념

```
joint 1이 회전하면서 joint 2도 움직이는 경우:

       ω₁ (joint 1 회전)
        ↺
        ●
       /
      / ── ω₂ (link 2가 link 1 기준으로 회전)
     ●
```

링크 1이 회전하면서 링크 2도 운동하면, **두 회전의 교차 효과**로 추가 힘이 발생해.

### 계산식

```
코리올리 토크 = C(q, q̇) · q̇

C(q, q̇)의 각 원소:

         n    ∂Mᵢⱼ   1 ∂Mᵢₖ
Cᵢⱼ(q,q̇) = Σ [ ─── - ─ ─── ] · q̇ₖ
        k=1  ∂qₖ    2 ∂qᵢ

Mᵢⱼ = 관성 행렬 M(q)의 (i,j) 원소
```

### 핵심 특성

```
두 관절 속도의 곱에 비례:

  C·q̇  ∝  q̇ᵢ · q̇ⱼ   (i ≠ j)

→ 한 관절이라도 정지(q̇=0)하면 코리올리 항 = 0
→ 빠르게 움직일수록 코리올리 효과 커짐
```

## 4. 원심력 토크

### 개념

```
joint 1이 회전할 때 link 2는 바깥으로 밀려나려는 힘을 받음:

      ↺ ω
      ●
     /
    /   ──→  원심력 (바깥 방향)
   ●
```

### 계산식

```
원심력 토크 ∝  q̇ᵢ²   (같은 관절 속도의 제곱)

수학적으로 C(q,q̇) 행렬 안에 함께 들어 있어:

  코리올리 항:  Cᵢⱼ · q̇ᵢ · q̇ⱼ  (i ≠ j)
  원심력 항:    Cᵢᵢ · q̇ᵢ²       (i = j)
```

### 코리올리 vs 원심력 비교

```
                코리올리              원심력
─────────────────────────────────────────────
발생 조건    두 관절이 동시에 회전    한 관절만 회전해도 발생
비례 관계    q̇ᵢ · q̇ⱼ (서로 다른)    q̇ᵢ² (자기 자신)
방향         회전 방향에 수직         회전 중심에서 바깥쪽
```

## 5. MuJoCo의 `qfrc_bias`

```
┌──────────────────────────────────────────────────┐
│                                                  │
│   qfrc_bias = C(q,q̇)·q̇ + g(q)                  │
│                                                  │
│   (코리올리 + 원심력 + 중력을 한 번에 계산)          │
│                                                  │
│   내부적으로 Recursive Newton-Euler 알고리즘 사용   │
│   O(n) 계산량 — 매우 빠름                          │
│                                                  │
└──────────────────────────────────────────────────┘
```

`mj_step()` 호출 때마다 자동 갱신되기 때문에 그냥 읽어서 더해주면 돼.

## 6. 중력 보상 전후 비교

```
보상 없는 PD:

  τ = Kp·e + Kd·ė

  → Kp가 중력을 버텨야 하므로 정상상태 오차 발생:

       목표값 ─────────
                       \
  실제값 ───────────────●  ← Kp·e = g(q)가 될 때 평형
                            (e > 0 인 채로 정지)


중력 보상 PD:

  τ = Kp·e + Kd·ė + g(q)

  → g(q)가 별도로 보상되므로 PD는 오차만 담당:

       목표값 ─────────
                       \
  실제값 ───────────────● ← e = 0에서 평형
```

## 요약

| 항 | 기호 | 의존성 | 특징 |
|---|---|---|---|
| 중력 | g(q) | 자세(q)만 | 정지해도 존재 |
| 코리올리 | C(q,q̇)·q̇ 중 교차항 | 두 관절 속도 곱 | 고속 다관절 동작 시 큼 |
| 원심력 | C(q,q̇)·q̇ 중 대각항 | 관절 속도 제곱 | 고속 단관절 회전 시 큼 |
| **합계** | **qfrc_bias** | q, q̇ | MuJoCo가 자동 계산 |
